# SAT Math Practice

Live at: https://khaydarovanvar.github.io/satbank/

An installable, offline-first SAT Math practice app with 500+ real SAT-style questions, written lessons (EN/UZ/RU), progress tracking, and a built-in Desmos graphing calculator.

## Features

- 500+ Math practice questions covering every Digital SAT Math skill
- Trilingual lessons (English / Uzbek / Russian) with real worked examples and Desmos solutions where applicable
- Progress tracking — solved questions are marked with a blue tick, saved locally and (once signed in) synced across devices
- Installable as a PWA — "Add to Home Screen" on mobile, works offline after first load
- Built-in Desmos calculator, floating or split-screen
- Sign in with Google for cross-device progress sync (via Firebase)

## Usage

Just open the live link above, or clone this repo and open `index.html` in a browser.
